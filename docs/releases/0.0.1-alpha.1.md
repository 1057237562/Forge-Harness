# Forge Alpha 0.0.1

首个 alpha 预发布版本，标签 `v0.0.1-alpha.1`。

## 安装包

- `forge-online-0.0.1-alpha.1-arm64.apk`：已签名的 online release APK。
- 应用 ID：`dev.forge.mobile`；版本名称：`0.0.1-alpha.1`；versionCode：6。
- 支持 ARM64，最低 Android 8.0（API 28）。可选 Agent 运行环境需联网下载和配置。
- `SHA256SUMS.txt` 提供安装包校验值。

## 本次内容

- Android 原生工程编译、构建诊断、安装结果持久化及 Java/Kotlin 工具链集成。
- 默认采用从固定 AOSP 源码重建的 aapt2 与 zipalign。
- DeepSeek Harness 重试次数与原因展示、分阶段无进展超时，以及不依赖 idle 的终止处理。
- 成功 SDK 结果不会因进程清理的非零退出码或 stdin 关闭而误报失败。

## 验证与限制

发布前运行应用 JVM 测试、`assembleOnlineRelease` 和 `lintOnlineRelease`，并校验
APK 签名、应用 ID、版本及 ARM64 架构。具体结果和签名证书摘要见 Release 附件
`release-verification.json`。

这是早期测试版本；真实模型在网络故障下的恢复、完整可见 UI 流程以及所有工程类型
尚未全部验收。发布包使用专用 alpha 签名；若手机上已有其他证书签名的调试版，
安装前需先备份重要项目和数据，再卸载该调试版。
