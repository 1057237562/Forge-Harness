用户点击 Apply Forge config 后才写入；预览提示该 JSON 将成为 Forge 的权威构建配置。
保留原源码和 Gradle 文件，应用前核对输入摘要，拒绝过期预览和已有配置文件。

进程在写盘途中死亡可能留下不完整的新配置，解析器会拒绝它；当前不声称具备该迁移事务的自动恢复。

验证：3 个单元测试通过，覆盖预览不改文件、成功迁移、原源码摘要保留、已有配置/过期预览/
SDK 不匹配拒绝及不为未知工程生成掩盖问题的配置。
